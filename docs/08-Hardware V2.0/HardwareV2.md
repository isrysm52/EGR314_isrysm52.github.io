## Improvements

There were multiple ways to improve the hardware design in this subsystem. The three main ponts will be discussed here, but there is always room for improvement and it is not constrained to only these three ideas. 

### Button Placement

To start, all of the buttons were used in the schematic. This was not the plan, but worked becasue of the spare buttons installed in case of emergencies. What this meant was that there were no more spare buttons. I would have added a few more buttons on the side to still keep the option of rerouting buttons in case of damage, wiring, or other issues. 

Additionally, the buttons were all pressed together in a small format that resembles a D-pad controll, but I would have spaced them out a bit more so that the buttons could be pressed comfortably instead of having to arch each finger to press one button and advoid the others. This also goes with the boot and enable buttons. Since they are on seperate sides of the PCB, it was difficult to boot. I would have wanted another ground layer to move the Boot button next to the enable button or vice versus. This would keep them together and would ease the placement of other buttons so I am not fearing accidentially pressing either button. 

### OLED Screen Flexibility

The OLED Screen was placed on the side of the PCB. Ther are two parts of this that I would change: the placements and the accessability. The OLED was placed in a way that it was facing left of the board. THis was an oversight on my part and I should have placed it facing downwards. Having it face downwards would make it easier to read the OLED screen instead of cranning your neck to look on the side of the pcb. 

The other, more preferred, option would be to use wires and have a seperate housing for the OLED screen. This could work because the component on the PCB is a 4-pin connector housing. This would make it easy to get 4 wires and have the OLED connected outside the controller. By doing so, I could have used a bigger OLED and instead of each piece of information overwriting the other, I could have them seperated in their own sections. 

### Size and Dimensions

Lastly, the size of the PCB was bulky. I used up as much space as was allowed, but I think that did more harm than good. For the controller shousing it made it bulky and hard to handle. The sharp edges also cut into the hand if not using the housing. Overall, if the PCB could have been shaped more like a controller and less boxy, then there would be a better ease of use when using the PCB.
